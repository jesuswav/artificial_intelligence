# Aprendizaje Máquina  
## Tipos de aprendizaje y estructura de un sistema ML

Licenciatura en Ingeniería en Tecnologías de la Información  
y en Innovación Digital  

---

## Objetivo de la sesión

Comprender los diferentes tipos de aprendizaje máquina y los componentes
que integran un sistema de Machine Learning, para su correcta aplicación
en la solución de problemas reales.

---

## ¿Qué es un sistema de Aprendizaje Máquina?

Un sistema de Machine Learning es un conjunto de procesos que permite:

- Analizar datos
- Identificar patrones
- Generar modelos
- Apoyar la toma de decisiones

Todo sin ser programado de forma explícita para cada caso.

---

## Componentes básicos de un sistema ML

Un sistema de aprendizaje máquina se compone de:

- Datos de entrada
- Proceso de aprendizaje
- Modelo matemático
- Métricas de evaluación
- Resultados o predicciones

---

## Tipos de Aprendizaje Máquina

El aprendizaje máquina se clasifica principalmente en:

- Aprendizaje supervisado
- Aprendizaje no supervisado
- Aprendizaje por refuerzo

Cada uno responde a diferentes tipos de problemas.

---

## Aprendizaje Supervisado

Características principales:

- Utiliza datos etiquetados
- Aprende a partir de ejemplos conocidos
- Se usa para predicción y clasificación

Ejemplos de uso:
- Predicción de precios
- Clasificación de correos
- Diagnóstico asistido

---

## Aprendizaje No Supervisado

Características principales:

- Utiliza datos sin etiquetas
- Busca patrones ocultos
- Agrupa información similar

Ejemplos de uso:
- Segmentación de clientes
- Análisis exploratorio
- Detección de anomalías

---

## Aprendizaje por Refuerzo

Características principales:

- Aprende mediante prueba y error
- Se basa en recompensas y penalizaciones
- Muy usado en sistemas autónomos

Ejemplos de uso:
- Robótica
- Videojuegos
- Optimización de procesos

---

## Flujo general de un sistema ML

1. Recolección de datos  
2. Preparación y análisis  
3. Selección del modelo  
4. Entrenamiento  
5. Evaluación  
6. Uso del modelo en producción  

---

## Importancia de los datos

- La calidad del modelo depende de la calidad de los datos
- Datos incorrectos generan decisiones incorrectas
- El análisis previo es fundamental

---

## Ética y responsabilidad en Machine Learning

El uso de ML debe considerar:

- Uso responsable de la información
- Privacidad de los datos
- Impacto social de las decisiones automatizadas

---

## Cierre de la sesión

- El Machine Learning no es solo el modelo
- Los datos y el proceso son igual de importantes
- La correcta clasificación del tipo de aprendizaje es clave
